# 问题解决记录 

## 问题1：写 README 链接的时候不知道路径怎么写
- 现象：不清楚路径的选择
- 原因：不熟悉相对路径写法
- 解决：同目录文件使用  ./文件名  的格式编写跳转链接
 
## 问题2：不知道提交后的检查
- 现象：分不清提交成功后，会不会自动更新 PR
- 原因：不熟悉 PR 和远程仓库的联动效果
- 解决：向这个 fork 仓库 main 分支 push 新提交，PR 会自动追加变更
 
## 问题3：对任务考核内容的理解
- 现象：一次性要新建好几个 md 文件，容易漏掉其中一个
- 原因：同时操作多个文件，记不清哪些已经提交
- 解决：建好一个核对一个，对照任务清单逐个确认

## 问题4：cd 切换目录失败
- 现象：Git Bash 输入 cd 命令，提示目录不存在
- 原因：记错仓库路径、文件夹名称输错
- 解决：先用  pwd  查看当前位置， ls  列出目录内容，确认文件夹名称后再执行 cd
 
## 问题5：nano 无法编辑文件
- 现象：打开文件显示只读，不能修改保存
- 原因：Windows 下 nano 权限兼容异常，文件被锁定
- 解决：改用 VS Code 修改保存文件，再回到命令行执行 git 操作
 
## 问题6：git push 推送被拒绝
- 现象：推送命令执行报错，提交上传失败
- 原因：远程仓库已有更新，本地版本落后于远程
- 解决：先  git pull  拉取远程最新代码，合并完成后再 add、commit、push
 
## 问题7：拉取代码出现合并冲突
- 现象：文件里面出现  <<<<<<<  这类冲突标记
- 原因：本地和远程修改了文件同一个位置，Git 无法自动判断内容
- 解决：VS Code 打开文件，删除冲突标记，保留需要的内容，保存后重新提交
 
## 问题8：创建 PR 找不到自己 fork 的仓库
- 现象：GitHub 网页对比分支时，下拉列表看不到自己的仓库
- 原因：没有开启跨 fork 对比，页面默认只在原仓库内对比
- 解决：点击 compare across forks，来源仓库选择自己 fork 的仓库，再创建 PR
 
## 问题9：修改文件后 git status 看不到改动
- 现象：VS Code 修改保存文件，git status 没有显示修改
- 原因：当前位置不在 git 仓库目录里
- 解决：切换到仓库根目录，使用  git status  确认仓库状态
 
## 问题10：commit 弹出 vim 编辑器卡住
- 现象：提交代码时跳出黑色 vim 界面，不知道怎么退出
- 原因：commit 没有加  -m  写备注，自动调用 vim
- 解决：按 Esc，输入  :q!  退出，重新提交并加上提交备注
